## Project overview

**Pages**

| Route             | Description                                                                          |
| ----------------- | ------------------------------------------------------------------------------------ |
| `/`               | Home: bento grid — profile tile, live local-time clock, stats, latest log entries, one tile per interest |
| `/log/`           | All entries as cards, with a search box and topic filter chips (`/log/?topic=linux&q=chmod` links work) |
| `/log/<slug>/`    | A single entry: reading-progress bar, header tile with topics, "jump to section", older/newer tiles |
| `/about/`         | Profile card (avatar, name, role, links) + bio (if set) + interests                  |
| `/404.html`       | "Signal lost" page with a glitching 404                                              |
| `/rss.xml`, `/sitemap-index.xml`, `/robots.txt` | Generated feeds and indexes                            |

**Features**

- **Animated synthwave background** — a neon perspective grid that endlessly rolls toward the
  viewer, a big striped sun sinking behind two layers of mountains, a glowing horizon line, stars
  and CRT scanlines (dark theme). The scene pans with the mouse. Light theme: pastel "vaporwave"
  daytime version. Paused in background tabs, a still frame for visitors who prefer reduced
  motion, CSS gradient fallback without JavaScript.
- **Floating dock navigation** at the bottom of the screen (Home · Log · About) on every screen
  size, plus a small top bar with the site name and a light/dark button.
- **Tiles everywhere**: rounded translucent tiles that lift with a neon glow on hover, and pop in
  one after another when a page loads.
- **Log**: Markdown/MDX entries, instant search and topic filters (no extra pages), drafts,
  reading time (English + CJK), build-time syntax highlighting with a copy button, optimized
  cover images.
- **SEO**: canonical URLs, Open Graph/Twitter tags, sitemap, RSS, robots.txt.
- **Responsive and accessible**: works down to phone width, skip link, keyboard focus styles.

## Tech stack

| Area              | Technology                                                                 |
| ----------------- | -------------------------------------------------------------------------- |
| Framework         | [Astro](https://astro.build) 7 — static site generation                    |
| Language          | TypeScript (strict), Astro components, plain CSS (custom properties)       |
| Content           | Astro Content Collections (Markdown / MDX via `@astrojs/mdx`)              |
| Code highlighting | Shiki (built into Astro), dual light/dark themes                           |
| Images            | `astro:assets` + `sharp` (converted to responsive WebP at build time)      |
| Feeds / SEO       | `@astrojs/rss`, `@astrojs/sitemap`                                         |
| Background        | HTML Canvas 2D + `requestAnimationFrame` (no libraries)                    |
| Search / filter   | Vanilla JS over data attributes on the log cards                           |
| Type checking     | `@astrojs/check`, TypeScript                                               |
| Runtime (build)   | Node.js ≥ 22.12                                                            |
| Web server        | Nginx                                                                      |

Generated (git-ignored): `node_modules/`, `.astro/`, `dist/` (build output), `release/` (tarballs).

## Getting started

```bash
npm install
npm run dev          
```

| Command                    | What it does                                                    |
| -------------------------- | --------------------------------------------------------------- |
| `npm run dev`              | Local dev server with hot reload                                |
| `npm run new -- "Title"`   | Create `src/content/posts/title.md` as a draft                  |
| `npm run check`            | Type-check components and validate entry frontmatter            |
| `npm run build`            | Build the static site into `dist/`                              |
| `npm run preview`          | Serve `dist/` locally to double-check   |
| `npm run package`          | check + build + create `release/blog-dist-<timestamp>.tar.gz`   |
| `npm run standalone`       | build + write `./index.html`: the home page as one self-contained file that opens directly in a browser |

> `./index.html` is generated — edit `src/data/profile.ts` / `src/pages/index.astro` and re-run
> `npm run standalone` instead of editing it by hand. It previews the home page only: the dock
> links work on the deployed site, not when the file is opened locally.

### Writing an entry

```yaml
---
title: 'My Entry'                # required
description: 'One sentence.'     # required — shown on cards, in RSS and as the subtitle
pubDate: 2026-11-17              # required
updatedDate: 2026-11-20          # optional
tags: ['devops', 'linux']        # optional — become filter chips on /log/
draft: true                      # optional — shown in `npm run dev` only
cover: ../../assets/covers/x.png # optional — relative to the entry file
coverAlt: 'Description'          # optional
---
```

## Customizing

| What                                  | Where                                                         |
| ------------------------------------- | ------------------------------------------------------------- |
| Domain, site title, your name, dock items | `src/config.ts` (`SITE.url` must be your real domain/IP — used for canonical URLs, RSS, sitemap) |
| Social links (hidden while empty)     | `SOCIAL_LINKS` in `src/config.ts`                             |
| Role, location, intro, bio, interests | `src/data/profile.ts` (empty fields are hidden)               |
| Avatar photo                          | Put `avatar.jpg` in `public/`, set `avatar: '/avatar.jpg'` in `profile.ts` (initials shown otherwise) |
| Interest icons                        | `code, camera, book, music, mountain, gamepad, coffee, plane` (add more in `src/components/icons.ts`) |
| Background colors / grid / sun        | `PALETTES` in `src/components/SynthBackground.astro` (sky, sun, mountains, grid colors); grid speed in `drawFloor()` |
| Theme colors, tile opacity, gradient  | CSS variables at the top of `src/styles/global.css`           |
| Favicon                               | `public/favicon.svg`                                          |

## Deployment (Nginx)

### 1. Build the bundle

```bash
npm ci               # clean install from package-lock.json
npm run package      # → release/blog-dist-YYYYMMDD-HHMMSS.tar.gz
```

### 2. Upload and extract

```bash
scp release/blog-dist-*.tar.gz user@server:/tmp/
ssh user@server
sudo mkdir -p /var/www/blog
sudo tar -xzf /tmp/blog-dist-*.tar.gz -C /var/www/blog
sudo chown -R www-data:www-data /var/www/blog   # Nginx user: www-data (Debian/Ubuntu), nginx (RHEL)
```

### 3. Configure Nginx

Edit `server_name` and `root` in `deploy/nginx.conf`, then install it:

```bash
# Debian/Ubuntu
sudo cp deploy/nginx.conf /etc/nginx/sites-available/blog.conf
sudo ln -s /etc/nginx/sites-available/blog.conf /etc/nginx/sites-enabled/blog.conf
# RHEL/CentOS/Alpine: sudo cp deploy/nginx.conf /etc/nginx/conf.d/blog.conf

sudo nginx -t && sudo systemctl reload nginx
```
